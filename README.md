# type-a-thon

## Typing Test Project For FOP
This is a typing test made specifically for our group <cout> and acts as our project for the course WIX1002 (Fundamentals of Programming). This repository serves as a place for us to upload our code and edit it throughout the duration of this project. This project is ran entirely on Java and JavaFX.
